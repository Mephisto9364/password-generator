# password-generator
A simple CLI password generator written in Python. Supports custom length, digits, special characters, and saving passwords to a file.
## Features

- Generate passwords from 5 to 100 characters
- Optional digits (0-9)
- Optional special characters (!@#$%...)
- Guaranteed at least one uppercase and one lowercase letter
- Copies the generated password to the clipboard
- Optionally saves passwords to `Passwords.txt`
